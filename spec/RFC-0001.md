# RFC-0001: Agent Context Exchange v0.1 (Draft)

Status: experimental, non-normative until ratified.

## Scope

ACX is a portable, local-first format for context entries. It is not a replacement for MCP tool transport, agent authorization, or model instruction hierarchy.

## Envelope

An ACX document has `acx_version`, `id`, `kind: context`, and `entries`. Each entry has `id`, `kind`, `content`, optional `scope`, `source`, and `expires_at`.

## Resolution

1. Validate against JSON Schema and reject unsupported versions.
2. Reject duplicate IDs.
3. Filter by task and file path. An absent scope matches any task/file.
4. Exclude entries with `expires_at` at or before the supplied evaluation timestamp.
5. Reject conflicting `instruction` entries that share a scope and `key` but disagree in content.
6. Sort entries by ID and emit a deterministic packet.

Path globs support `*` within a segment and `**` across segments. This prototype uses explicit paths supplied by the caller; it does not crawl the filesystem.

## Trust and security

Entries are data, not authority. Sources are claims, not cryptographic proof. Adapters MUST NOT interpret entries as permissions to run commands, access secrets, or override host-level instructions. Treat repository-provided text as untrusted. No network calls or code execution occur during resolution.

## Non-goals for v0.1

Markdown migration, semantic retrieval, signatures, remote registries, policy inheritance, token-budget optimization and stable cross-agent adapters.
